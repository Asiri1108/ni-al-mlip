LAMMPS STAGE B -- AL3NI5 ALPHA-ANGLE DEVIATION DIAGNOSTIC
Read-only, 2026-08-19. No new DFT run.

1. WAS AL3NI5 ALREADY TRICLINIC IN DFT?
DFT reference cell angles, all 5 phases:
  phase       alpha      beta     gamma   triclinic(any != 90 deg)?
  AlNi      90.00000  90.00000  90.00000  False
  Al3Ni     90.00000  90.00000  90.00000  False
  Al3Ni2    90.00000  90.00000 120.00001  True
  Al3Ni5    96.47808  90.00000  90.00000  True
  AlNi3     90.00000  90.00000  90.00000  False

YES -- Al3Ni5's DFT reference already has alpha=96.478 degrees. force_skew=True
(the fix that let AlNi/Al3Ni/AlNi3 relax at all -- see Stage B's earlier
"Cannot specify Pxy/Pxz/Pyz in fix box/relax with non-triclinic box" fix) only
changes how ASE writes the LAMMPS data file header; it does not add any
physical degree of freedom Al3Ni5 didn't already have in the DFT ground
truth. Al3Ni2 is also genuinely triclinic (gamma=120, hexagonal) and its
relaxation stayed tight (max lattice % = 0.2087%, see Stage B report) --
confirms force_skew itself is not the source of Al3Ni5's larger deviation.

2. CONSTRAINED (aniso, angles fixed at DFT starting values) vs UNCONSTRAINED (tri) RE-RELAX
                        alpha (deg)   energy (eV)         fmax_final (eV/A)   stopping criterion
  unconstrained (tri):   98.27877    -24969.631035088     2.480e-09           force tolerance
  constrained (aniso):   96.47808    -24969.624053538     9.149e-05           linesearch alpha is zero

Energy difference (constrained - unconstrained): +0.0069816 eV total =
  +0.8727 meV/atom (8 atoms)

Context for that number, using this project's own established scales
(configs/ROUND285_SEALED_ACCEPTANCE_CRITERION.txt, project_knowledge.md
Section 5):
  - measured cross-seed noise floor: 0.43 meV/atom
  - locked acceptance threshold (cfg297/cfg299): 2.6183 meV/atom
  - this energy difference: 0.87 meV/atom -- ~2x the noise floor, well
    below the acceptance threshold.

INTERPRETATION: this is NOT a flat/zero-cost soft mode -- constraining the
angle back to the DFT value costs a real, non-negligible amount of energy
under THIS model (about double the model's own measured noise floor), and
the constrained run's residual fmax (9.1e-05 eV/A) is far above the
unconstrained run's (2.5e-09 eV/A), meaning there is a genuine unbalanced
internal force pushing toward the larger angle that the constraint is
suppressing. The model's internal PES has a real, if energetically modest,
preference for alpha ~98.3 deg over the DFT value of 96.5 deg at this
composition/volume.

CAVEAT (important, and why this is not a full verdict on model accuracy):
this only characterizes the MODEL's own PES shape. It does NOT establish
whether alpha~98.3 deg is closer to or further from the TRUE (DFT) minimum
than alpha=96.5 deg -- that would require a new DFT relaxation or at least
a DFT single-point at the shifted geometry, which is explicitly out of
scope for this diagnostic (no new DFT). So: "real, not a soft mode" refers
to the deviation being a genuine feature of the trained model's energy
landscape, not a numerical/relaxation artifact -- it does not by itself
prove the model is wrong relative to DFT at that angle, only that the 1.87%
Stage B number reflects a real energetic pull, not meaningless numerical
drift along a flat direction.

3. LINK TO CFG060?
cfg060_Al3Ni5_volume_rattle_expansion is confirmed Al3Ni5-phase (cell
angles 96.478/90/90, same alpha as the Al3Ni5_relaxed reference, consistent
with being a rattled/volume-perturbed member of the same phase family). It
is the config that has anchored the acceptance-threshold derivation's
per-seed maximum across ALL THREE tested seeds (20260811/812/813) --
configs/ROUND285_SEALED_ACCEPTANCE_CRITERION.txt: "the anchoring config
(cfg060) is IDENTICAL across all 3 seeds" -- i.e. Al3Ni5 is consistently
this model's worst-predicted reserved phase, not a single-seed fluke.

Checked TRAIN/VALIDATION density per phase (combined-227) as a candidate
common cause (sparse phase coverage -> both a soft/wrong equilibrium and
elevated held-out error would be a natural shared explanation):
  TRAIN:      AlNi=35  Al3Ni2=31  Al3Ni5=34  Al3Ni=54  AlNi3=35
  VALIDATION: AlNi=3   Al3Ni2=3   Al3Ni5=3   Al3Ni=6   AlNi3=3
Al3Ni5's raw TRAIN count (34) is unremarkable -- close to AlNi/AlNi3 (35
each), not conspicuously sparse. So a simple "too few Al3Ni5 structures"
explanation is NOT supported by count alone; if there is a shared cause it
is more specific than raw density (e.g. insufficient coverage specifically
along the shear/tilt direction that alpha moves in, rather than the phase
as a whole) -- not established here, would need a targeted check of TRAIN
geometry diversity along that specific direction, out of scope for this
read-only pass.

VERDICT: two independent signals (persistently-worst reserved-set error
across all 3 seeds; the only phase among 5 with a non-negligible energetic
angle deviation on relaxation) point at the same phase, Al3Ni5, as this
model's weakest region. Plausible common cause (this model is comparatively
least accurate/least well-constrained for Al3Ni5 specifically), but not
mechanistically demonstrated -- correlation (same phase, both times) without
an identified shared root cause.

Method
------
Force errors use every Cartesian component in eV/A. Aggregate metrics pool all
TEST force components. Stress errors use all six ASE Voigt components with the
same ASE sign convention for references and predictions. Aggregate stress pools
all 30 TEST components. Conversion: 1 eV/A^3 = 160.21766208 GPa.

Raw absolute QE energies were not compared with foundation energies. For every
phase, the evaluated quantity is:
  [E(test shear+rattle) - E(corresponding relaxed phase reference)] / atom.
The same exact relaxed structure is used for both models. These relaxed phase
references belong to canonical TRAIN-15. Therefore the energy metric is:
"held-out perturbation relative-energy error anchored to the corresponding
relaxed phase reference". It is not a fully independent absolute-energy test.
